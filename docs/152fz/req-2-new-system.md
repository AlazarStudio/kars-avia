# Требования 152-ФЗ к новой системе Kars Avia и Kars Hotel PMS

Kars Avia · ред. от 07.10.2026 · документ 2 из 3

Для руководства и ответственного за обработку персональных данных. Здесь — требования закона к системам, которые ещё не запущены в работу: новой системе Kars Avia (её готовит команда v3) и системе управления гостиницей Kars Hotel PMS. Текущая система — документ 1, организация — документ 3.

Как пользоваться. Отметку на дату редакции поставила команда разработки по коду обеих систем, а где это указано — по оценке команды v3; она же проверяет, если в строке не назван другой проверяющий; «не подтверждено» — по коду не проверить. «До запуска» — без этого работу не переводят на новую систему, а гостинице не выдают кабинет в PMS; раздел А — до запуска, А.1 и А.5 — сразу. «ПДН …» — пункт чеклиста мер аудита; «ждёт Р-N» — нужно решение руководства Р-N, его строка — в документе 3. Решение по случаям из отдельной записки ответственному — по документу 3.

Основания: 152-ФЗ «О персональных данных», ПП РФ № 1119, приказ ФСТЭК № 21, приказ Роскомнадзора № 179.

## Ж. Kars Hotel PMS

Собственные брони гостиницы PMS ведёт по её поручению (оферта); брони из Kars Avia — данные авиакомпаний, их передача — в пределах поручений авиакомпаний. Юрлицо — сторона оферты — по документу 3. Всё ниже — до выдачи кабинета первой гостинице.

| № | Что должно быть | Как проверить | Основание | Отметка |
|---|---|---|---|---|
| Ж.1 | В брони — только ФИО ведущего гостя, телефон, e-mail и комментарий с подсказкой «без диагнозов и документов»; гостиница видит только свои брони | Бронь другой гостиницы — отказ | 152-ФЗ ст. 5, 19 · Р-9 | частично · ждёт Р-9 |
| Ж.2 | Сервер PMS — в РФ (по оценке команды v3 — так); снаружи открыт только https, база закрыта. В работу PMS не запущена | Сканирование портов рабочего сервера — администратор | 152-ФЗ ст. 18, 19 | не подтверждено |
| Ж.3 | Обмен в обе стороны — только по https, с проверкой ключа отправителя. В PMS — данные гостя и брони, отчёты гостиницы, имя и e-mail диспетчера; из PMS — события без данных гостя | Тестовая бронь — обмен по https, событие без данных гостя | ФСТЭК № 21 | частично |
| Ж.4 | При выходе гостиницы её брони выгружаются ей и удаляются по акту; брони старше срока оферты обезличиваются. Сейчас гостиницу можно только отключить | Удалить тестовую гостиницу — броней нет — ответственный | 152-ФЗ ст. 6, 21 · Р-1 | нет · ждёт Р-1 |
