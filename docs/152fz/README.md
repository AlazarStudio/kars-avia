## Пересборка .docx

Исходники — Markdown-файлы этой папки; .docx собираются из них после каждой правки. Скрипт сборки лежит во внутренних материалах (вне git) со своими зависимостями (`docx`, `marked`) — в `package.json` фронта ничего не добавляется:

```bash
node docs/superpowers/152fz-work/build/md2docx.mjs
```

Аргумент `checklist` или `memo` собирает один документ. Черновики из `drafts/` входят в `02-legal-memo.docx` приложениями 1–7. Оглавление в .docx заполняется при открытии в Word (ответить «Да» на обновление полей). Проверка файла: `PYTHONUTF8=1 python ~/.claude/skills/docx/scripts/office/validate.py docx/<файл>.docx`.

Перед сборкой проверить:

- в файлах комплекта нет путей к коду, номеров строк, названий служебных полей и методов, секретов и персональных данных конкретных людей;
- ссылки между документами (`01-checklist.md`, `drafts/…`) в .docx заменены названиями документов или приложений;
- дата документов и редакция закона в шапках совпадают с этим файлом.
